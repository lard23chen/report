AI 講義

數據自動化與網頁部署實務

從 Excel／雲端試算表出發，走完分析、部署、回寫、資料庫化、排程與通知的完整流程

第一頁

課程大綱 (Agenda)

本課程將涵蓋以下八大核心主題：

1

數據分析與 HTML 產出

從 Excel 或雲端 Excel 讀取資料並分析產出 HTML 檔案。

 2

網頁部署

將產出的本地端 HTML 檔案推送 (Push) 到網站上顯示。

 3

雙向互動回寫

將讀取的資料進行編輯並回寫到 Excel 檔案或雲端 Excel。

 4

個人化應用

建立個人程式列表（如知識庫或生活管理系統）。

 5

資料庫整合

將 Excel 資料轉入 MongoDB。

 6

自動化排程

使用排程工具將每日資料進行自動更新。

 7

即時通知系統

當資料更新完成後，自動進行 LINE 通知。

 8

系統優化與安全

整體系統效能優化與資訊安全防護。
第二頁

環境建置與 HTML 自動產出

  • 工具安裝：安裝 Antigravity，需準備 Gmail 帳號並搭配 Gemini Pro。
  • 參考資源：
    • 官方教學網頁
    • 下載連結
    • 安裝教學影片
  • 實作任務：讀取指定的雲端 Excel 資料。開啟雲端 Excel
  • AI 指令 (Prompt)：分析上述網址資料並產出 XX.html 檔案。
    ⬇ 下載 hotel.html 範例
  • 檔案管理：統一存放於本地端路徑 D:\AI\report。
第三頁

GitHub 網頁部署實務

  • 帳號準備：申請 GitHub 網站帳號。前往 GitHub
  • Repository 設定：進入 Settings 確認 Default branch 設定為 main。
  • AI 推送指令 (Prompt)：將 XX.html 檔案 commit 並 push 到 GitHub 網站，完成後提供瀏覽網址。
    產出結果：https://lard23chen.github.io/report/hotel.html
第四頁

資料回寫與雙向編輯實務

  • 實作編輯介面，讓使用者能直接修改數據。
  • 開發回寫機制，將編輯後的內容同步更新至原始 Excel 檔案或雲端 Excel。
  • 設定讀寫權限，確保資料傳輸的準確性。
第五頁

實作場景：個人程式列表與知識庫

利用所學技術建立個人化工具：

  • 知識庫：彙整程式碼片段與學習筆記。
  • 生活管理：建立待辦事項或資源追蹤列表。
  • 視覺化呈現：透過自動產出的 HTML 提升閱讀與搜尋效率。
  • AI 推送指令 (Prompt)：將 XX.html 檔案依上圖列表格式進行資訊管理。
第六頁

進階數據管理：Excel 轉入 MongoDB

  • 當資料需求擴張時，將 Excel 資料轉移至 MongoDB 資料庫。
  • 學習 MongoDB 的基本設定。
  • 使用 AI 協助編寫轉換腳本，將結構化資料映射至 NoSQL 文件格式。
第七頁

自動化流程與 LINE 通知

  • 自動更新：設定每日定時執行的排程，確保數據的時效性。
  • 即時回報：整合 LINE Notify 或 Bot，在資料更新完成後立即傳送通知訊息。
第八頁

系統優化與資訊安全

  • 效能優化：針對整體作業流程進行優化調教。
  • 資訊安全：重點在於保護 API Key、GitHub Token 以及資料庫存取憑證，防止敏感資訊外洩。
