Phase 2 全自動發布前，這 5 件事要先做完

⚠️ 這些步驟都需要在 Facebook / IG App / Meta / Google 官方頁面上手動操作（建帳號、申請 App、授權憑證），Claude 無法代為執行。完成後把要求的資訊（App ID、Secret、憑證檔）貼回聊天室即可繼續。
1

建立匠名 IG 帳號

IG App ▼
1
用一組新 Email／手機號碼，在 IG App 註冊全新帳號（不要用原本帳號改名，避免舊追蹤者、舊互動紀錄留下痕跡）
2
大頭貼、Bio 採去識別化設定（不放清晰正臉照、不寫真實姓名/公司/學校）
3
右上角 ☰ → 設定和隱私 → 帳號類型和工具 → 切換為「創作者帳號」或「商業帳號」（一般個人帳號無法用 Graph API 發文）
4
逐一檢視原本帳號的追蹤清單，用匠名帳號封鎖/取消追蹤已知聯絡人（IG 沒有批次封鎖 API，只能手動）
✅ 完成後不用回報任何資訊，勾選下方即可
已完成匠名帳號建立
2

建立 Facebook 粉絲專頁並綁定 IG

Facebook ▼
1
開 facebook.com/pages/create，名稱填匠名帳號名稱（不要用真名）
2
類別選「個人部落客」或「數位創作者」，建立完成即可，不用填其他資料
3
用匠名 IG 帳號登入 IG App → ☰ → 設定和隱私 → 帳號中心
4
帳號中心 → 帳號 → 新增帳號 → 選「連結專頁」→ 選剛建立的 FB 粉絲專頁
5
確認綁定成功，且 IG 帳號類型仍是創作者/商業帳號
已完成粉絲專頁綁定
3

建立 Meta Developer App

Meta for Developers ▼
1
開 developers.facebook.com → 右上角「開始使用」（用綁定粉絲專頁的同一個 FB 帳號登入）
2
「建立 App」→ 類型選「其他」→「商業」
3
App 名稱可填 IG Anon Auto Publish
4
控制台左側「產品」→ 找「Instagram」→「設定」加入此產品
5
左側「應用程式設定」→「基本資料」，記下 App ID 與 App Secret
📋 完成後把 App ID 和 App Secret 貼回聊天室給 Claude，用來換取 Access Token
已取得 App ID / App Secret
4

Google Cloud 啟用 Drive API

Google Cloud Console ▼
1
開 console.cloud.google.com，建立新專案（例如 ig-anon-auto-publish）
2
左上角選單 → 「API 和服務」→「已啟用的 API 和服務」→「啟用 API 和服務」，搜尋並啟用 Google Drive API
3
左側「憑證」→「建立憑證」→「服務帳號」，填名稱後建立
4
在該服務帳號頁面 →「金鑰」分頁 →「新增金鑰」→ 選 JSON，下載憑證檔（妥善保管，不要外流或上傳到公開 repo）
5
在 Google Drive 建立 IG_AutoPost/inbox 資料夾，用「共用」把該服務帳號的 Email（在 JSON 憑證裡的 client_email）加為協作者，才能讀取資料夾內容
📋 完成後把下載的 JSON 憑證檔路徑（或內容）告訴 Claude，用來設定雲端 Worker 的存取權限
已取得 Drive API 服務帳號憑證
5

選定雲端主機（24/7 跑 Worker）

Railway 或同等服務 ▼
1
確認要用哪個雲端服務常駐跑 Node.js（例如 Railway、Render、Fly.io），需要能接受背景 worker（不是只能跑網頁）
2
確認該服務的帳號/付款方式已設定好（背景常駐服務通常不是完全免費方案）
📋 告訴 Claude 你選定哪個平台，即可依平台規格寫部署設定
已選定雲端主機
