⚠️ 錯誤碼 2147946720（0x800710E0）排查指南

常見原因

  • BAT 未設定 WorkingDirectory，Node.js 找不到相對路徑腳本
  • MongoDB 連線逾時（網路異常或連接數超限）
  • Git commit 無差異（nothing to commit），bat 以非零碼退出

排查步驟

  1. 查看 daily_log.txt 確認 Node.js 輸出內容
  2. 確認 Qware_Daily_Report_Update_Final 的 Last Result 是否為 0（成功即代表報表已更新）
  3. 手動執行 BAT，觀察 Command Prompt 錯誤訊息
  4. 若為 Git commit 問題，於 BAT 加入 git diff --quiet || git commit -m "..." 條件判斷

🛠️ 新增排程程式規範

  1. 撰寫 .bat 或 .ps1，結果輸出至 *_log.txt
  2. 在 Windows 工作排程器建立任務，務必設定 WorkingDirectory
  3. 更新 REPORT_SPEC_SCHEDULED_TASKS.md §1 排程總覽表
  4. 更新本 HTML 儀表板的排程表格與 BAT 卡片
  5. 在 HTML_Report_Catalog.html 總目錄「⏰ 自動排程程式」區段新增一列
